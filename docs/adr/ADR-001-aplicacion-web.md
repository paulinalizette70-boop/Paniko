# ADR-001 — Elegir una aplicación web para Paniko

- **Estado:** decisión documentada en el acta; implementación por ratificar.
- **Referencia:** acta del proyecto, versión 1.0, septiembre de 2026.

## Contexto
El equipo necesita un MVP universitario de gestión de producción panadera dentro de un calendario limitado.

## Decisión
Desarrollar una aplicación **web** para ingredientes, recetas y producción. La aplicación móvil nativa queda fuera del alcance del MVP.

## Justificación
Una solución web permite acceso desde navegadores y reduce el esfuerzo de crear versiones específicas para varios sistemas operativos.

## Consecuencias
Será necesario verificar compatibilidad de navegadores y disponibilidad de servidor. Las funciones sin conexión no están contempladas en el acta.

## Pendiente
Corroborar la decisión con la implementación y actualizar el ADR si hay cambios.
